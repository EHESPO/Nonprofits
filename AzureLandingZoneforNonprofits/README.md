# Azure Landing Zone for Nonprofits – USA Edition

A ready‑to‑use cloud foundation built specifically for smaller U.S. nonprofits. This Azure Landing Zone delivers a preconfigured environment that follows Microsoft best practices — helping you deploy secure, compliant, and scalable cloud infrastructure without starting from scratch.

## What’s included

- Core Azure services for networking, identity, security, and management  
- Guided setup aligned with nonprofit IT needs  
- A foundation ready for migration, modernization, and AI innovation  

## Why use it

Nonprofits often face limited IT resources and strict compliance requirements. This landing zone removes the guesswork, so you can focus on your mission while Azure handles the underlying security and governance.
